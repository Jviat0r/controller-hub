    Which controller?

        Settings

        Drivers

          Xbox 360, Xbox One and Xbox Series controllers use the driver built into Windows. PlayStation controllers need ViGEmBus so games see them as an Xbox pad. HidHide is optional and stops games from seeing the PlayStation pad twice.

          Behaviour

          Closing the window keeps the hub running in the tray so your controllers stay connected. Use Quit in the tray menu to stop it.
